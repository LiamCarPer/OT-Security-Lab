# Sigma Rules

Portable Sigma rules for the lab's OT and endpoint detections. The live Loki
bundle under `siem/rules/ot_*.yaml` is generated by
[ot-detection-engineering](https://github.com/LiamCarPer/ot-detection-engineering);
these Sigma files are the vendor-neutral source artifacts.

| Rule | Log source | Technique | Validation |
| :--- | :--- | :--- | :--- |
| `cross_zone_violation.yml` | OT gateway | T0886 | Live compliance scenario |
| `modbus_unauthorized_write.yml` | OT Modbus | T0831 | Live compliance scenario |
| `modbus_brute_force.yml` | OT Modbus | T0846 | Live compliance scenario |
| `process_safety_violation.yml` | OT process monitor | T0836 | Live compliance scenario |
| `ot_port_scan.yml` | OT gateway | T0846 | Live nmap scenario |
| `edr_suspicious_modbus_client.yml` | Windows Sysmon | T0884 | Static sample telemetry |
| `powershell_ot_modbus_client.yml` | Windows PowerShell 4104 | T0831 / T1059.001 | Static (no Windows EDR in lab) |
| `powershell_ot_conduit_discovery.yml` | Windows PowerShell 4104 | T0846 / T1059.001 | Static (no Windows EDR in lab) |

`tests/test_sigma_rules.py` enforces required metadata, unique IDs, a detection
condition, and ATT&CK for ICS tags against the vendored catalog. The PowerShell
rules are intentionally marked `experimental`: the lab runs PowerShell 7 on
Linux, so live 4104 validation requires a Windows endpoint and is tracked as a
known gap in `CLAIMS.md`.
